# TrafficAnalyzer

Приложение для анализа сетевого трафика с использованием PyQt5 и PostgreSQL.

## Настройка подключения к базе данных

Параметры подключения к базе данных находятся в файле `db_config.json`.  
Чтобы изменить настройки (хост, порт, имя базы, пользователя, пароль), просто отредактируйте этот файл — менять код не требуется.

## Запуск установочного скрипта и сборка исполняемого файла

В репозитории присутствует скрипт `install.bat`, который автоматизирует установку зависимостей и сборку исполняемого файла.

### Как использовать:

1. Убедитесь, что у вас установлен Python 3 и добавлен в системный PATH.
2. Скачайте или обновите проект из репозитория.
3. Откройте командную строку (CMD) и перейдите в папку с проектом, где лежит `install.bat`.
4. Запустите скрипт используя: `install.bat`

Скрипт выполнит следующие действия:
- Установит необходимые Python-зависимости из файла `requirements.txt`.
- Если отсутствует файл `db_config.json`, создаст его на основе шаблона `db_config.template.json`.
- Соберёт исполняемый файл `main.exe` с помощью PyInstaller в корневой папке проекта.

5. После успешного выполнения скрипта в папке с проектом появится файл `main.exe`. Его можно запускать без необходимости устанавливать Python или зависимости.

---

Если возникнут вопросы или ошибки — проверьте, что Python и pip корректно установлены, а также что файл `requirements.txt` присутствует в корне проекта.
