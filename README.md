Traffic Analysis Tool
Это приложение для анализа сетевого трафика с использованием PyQt5 и базы данных PostgreSQL.

Настройка подключения к базе данных
Параметры подключения к базе находятся в файле db_config.json. Чтобы изменить настройки (хост, порт, имя базы, пользователя, пароль), просто отредактируйте содержимое этого файла без необходимости менять код.
